# WorkPilot 用户体验优化建议

> 审查日期：2026-06-23  
> 审查角度：以一个真实用户（职场困惑者）的视角使用产品，从「打开首页 → 对话 → 获得帮助 → 长期使用」全流程提出改进建议。

---

## 优先级说明

- 🔴 高优先级 — 直接影响用户留存和核心体验
- 🟡 中优先级 — 提升使用效率和满意度
- 🟢 低优先级 — 锦上添花，体验细节

---

## 一、首次使用体验（首屏 & 引导）

### 🔴 1.1 缺少新手引导 / Onboarding

**现状**：用户进入首页直接看到输入框和场景卡片，没有介绍"这是什么"、"能做什么"、"数据安全吗"。

**问题**：职场问题具有隐私敏感性（比如"想离职"），用户在不了解平台安全性的情况下不敢说真话。

**建议**：
- 首次进入时展示一个轻量引导（3 步）：
  1. "这是你的职场智囊，所有对话只属于你"
  2. "说说你在烦恼什么，不用组织语言"
  3. "我会根据你的情况，连接最合适的专家帮你"
- 底部增加一行小字："对话存储在本地，我们不会分享给任何第三方"

### 🟡 1.2 首页缺少「我能做什么」的能力边界展示

**现状**：Bento 卡片只有 3 个场景（涨薪、离职、迷路），但实际能力有 26 层。

**建议**：
- 增加一行「更多能力」折叠区域：面试模拟、简历诊断、offer 对比、预约咨询
- 或在输入框 placeholder 中循环展示不同能力提示（类似 ChatGPT 的旋转 placeholder）

## 二、对话核心体验

### 🔴 2.1 意图路由对用户不透明

**现状**：用户发消息后，有一个 `routing-badge` 显示路由结果（如"路由到 → 简历优化专家"），但只是一闪而过的标记。

**问题**：
- 用户不知道为什么被路由到某个专家
- 如果路由错误，用户没有纠正手段

**建议**：
- 路由 badge 增加可点击的「不对？换一个」按钮
- 或者在首次路由时展示一句话解释："我判断你在问简历相关的问题，让简历专家来帮你。如果不对，可以告诉我。"
- NLU 澄清应该更友好：目前 ClarificationHandler 的追问是模板化的，建议加上 Agent 人格化语气

### 🔴 2.2 流式输出中缺少「停止生成」按钮

**现状**：`isStreaming` 期间输入框 disabled，用户只能等待。

**建议**：
- 添加一个「停止」按钮，点击后 `eventSource.close()` 并在当前回复后追加 "…（已中断）"
- 这对长回复特别重要（比如质量审查模式下，审查可能耗时较久）

### 🟡 2.3 多 Agent 群聊模式下消息气泡辨识度不足

**现状**：多 Agent 回答时有 `agent-label` 和 `getAgentAvatar()`，但视觉区分不够强。

**建议**：
- 每个 Agent 用不同的 accent color 做消息气泡左侧色带：
  - 简历专家 → 蓝色
  - 谈薪专家 → 金色
  - 离职专家 → 紫色
  - 通用顾问 → 绿色
- 气泡顶部加 Agent 身份卡片（一行）：`📝 简历优化专家`

### 🟡 2.4 对话开始后欢迎消息缺少「上下文感知」

**现状**：`CareerAdvisor.vue` 初始显示固定欢迎词。

**建议**：
- 如果用户有画像，利用画像动态调整欢迎词："上次你提到在考虑转行，有进展了吗？"
- 如果用户从首页 quick chip 进入，欢迎词应该直接回应该场景

### 🟢 2.5 对话气泡缺少「复制」按钮

**现状**：只有收藏按钮（hover 时显示星星）。

**建议**：
- 增加「📋 复制」按钮，用户经常需要复制 AI 给的话术/邮件模板
- 长回复增加「📁 导出为 PDF」快捷入口

## 三、会话管理体验

### 🟡 3.1 会话标题自动生成时机太晚

**现状**：新会话创建时标题固定为"新对话"，需要用户手动重命名。

**建议**：
- 第一次 AI 回复完成后，自动用 LLM 生成一个简短标题（如"谈薪策略讨论"）
- 或者取用户第一句话的前 15 字作为标题

### 🟡 3.2 侧边栏会话列表缺少分组

**现状**：所有会话按时间平铺。

**建议**：
- 按时间分组："今天"、"最近 7 天"、"更早"
- 或按意图 Agent 分类标签（简历/谈薪/离职）

### 🟢 3.3 会话删除缺少确认

**现状**：点击 × 直接软删除到回收站，没有确认对话框。

**建议**：
- 由于有回收站机制（可恢复），可以考虑加一个轻量 Toast："已移入回收站" + 撤销按钮，5 秒后消失

## 四、功能可见性与可达性

### 🔴 4.1 很多高级功能用户无法发现

**现状**：用户画像、执行轨迹、交付物、收藏、用量统计等功能藏在子页面或需要从 URL 直接访问。

**建议**：
- 在对话页面右上角增加一个功能菜单（…按钮）：
  - 👤 我的画像
  - ⭐ 我的收藏
  - 📊 使用统计
  - 📦 交付物
  - ⚡ 执行轨迹
- Home 页底部增加功能导航卡片

### 🟡 4.2 知识库上传功能入口隐蔽

**现状**：文件上传在 CareerAdvisor 的 📎 按钮里，但上传到知识库需要去 `/knowledge` 页面。

**建议**：
- 在对话中上传文件时，自动识别文件类型，询问用户："要把这个文件加入知识库吗？后续对话可以参考它。"
- 或者在 📎 弹出的菜单中区分："上传到本次对话" vs "加入知识库"

### 🟡 4.3 超级智能体入口不明确

**现状**：SuperAgent 是独立页面 `/chat/super`，但首页和对话页都没有明显入口。

**建议**：
- 在 CareerAdvisor 输入框旁增加一个模式切换开关："💬 对话模式" / "🤖 任务模式"
- 或当用户输入明显的任务型指令时（"帮我搜索…"、"生成一份…"），自动提示切换

## 五、反馈与信任感

### 🔴 5.1 AI 回复缺少「信息来源」标注

**现状**：RAG 召回的内容直接融入回复，用户不知道哪些是知识库内容、哪些是模型生成。

**建议**：
- 回复末尾增加「参考来源」折叠区域（类似 Perplexity）
- 标注："基于《职场常见问题和回答-求职篇》" + 可点击展开原文片段

### 🟡 5.2 质量审查结果展示不友好

**现状**：`quality-strip` 显示 riskLevel + 三维分数，用户看不懂。

**建议**：
- 将分数转化为用户语言：
  - LOW → ✅ 回答可靠
  - MEDIUM → ⚠️ 仅供参考，建议交叉验证
  - HIGH → 🚫 该建议风险较高，请谨慎采纳
- 隐藏具体分数，只在管理后台展示

### 🟡 5.3 画像构建过程不透明

**现状**：画像在后台异步构建，用户不知道系统在"了解自己"。

**建议**：
- 对话几轮后，出一个轻提示："我对你有了初步了解：关注薪资谈判、偏好简洁回答。如果不准确可以修改。"
- 画像面板增加「这不对」快捷修正按钮

## 六、移动端适配

### 🔴 6.1 侧边栏在移动端体验差

**现状**：有 collapsed 状态但切换按钮小，且搜索/归档操作不方便。

**建议**：
- 移动端改为底部 sheet（从底部滑出的半屏面板）展示会话列表
- 对话页全屏，会话切换通过顶部标题点击触发

### 🟡 6.2 Bento 卡片在窄屏压缩严重

**现状**：`@media (max-width: 768px)` 切换为单列，但描述文字可能截断。

**建议**：
- 窄屏改为水平滚动卡片（snap scroll），每张卡片固定宽度
- 或改为 2 列紧凑布局

---

## 七、性能与感知速度

### 🟡 7.1 SSE 首字延迟感知优化

**现状**：发送消息后 `isThinking` 显示三个跳动点，NLU + 路由完成后才开始流式。

**建议**：
- 在 NLU routing 阶段就推送事件："正在分析你的问题…" → "连接简历专家…" → 流式开始
- 让用户感知到系统在行动，而非只是"等待"

### 🟡 7.2 会话切换时历史加载无骨架屏

**现状**：切换会话时 `messages = []` 然后异步加载，有短暂白屏。

**建议**：
- 加载期间显示 3-5 个消息气泡骨架屏（灰色脉冲动画）
- 或保留上一个会话的最后几条消息做淡出过渡

---

## 八、长期使用粘性

### 🟡 8.1 缺少「进度追踪」和「行动清单」

**现状**：每次对话是独立的，AI 给的建议没有后续跟踪。

**建议**：
- 引入「行动项」概念：AI 给出建议时自动标记 TODO
- 下次打开时提醒："上次建议你准备 STAR 案例，准备好了吗？"
- 交付物系统已有 Artifact，可以扩展为用户可见的「我的行动清单」

### 🟡 8.2 缺少对话场景模板

**现状**：Quick chips 只有 5 个固定选项。

**建议**：
- 根据用户画像动态推荐："你之前关注离职，要不要看看离职时间线规划？"
- 增加更多结构化场景入口：
  - 📊 Offer 对比工具
  - 📝 面试模拟（模拟面试官提问）
  - 💼 职业测评
  - 📅 离职倒计时计划

### 🟢 8.3 缺少用户成就/里程碑

**建议**：
- 简单的里程碑系统："你已经用 WorkPilot 解决了 3 个职场难题"
- 给用户一种陪伴感和成长感

## 总结

WorkPilot 的技术架构已经非常完善（26 层能力），但**产品化包装和用户感知层面**还有提升空间。核心问题是：

1. **能力丰富但发现困难** — 用户只能看到冰山一角 ✅ 已解决
2. **AI 行为不透明** — 路由、画像、质检对用户黑箱 ✅ 已解决
3. **单次对话缺少延续性** — 没有行动追踪和进度感（长期规划）
4. **控制感不足** — 不能停止、不能纠正路由、不能修正画像 ✅ 已解决

已实现优化：
- ✅ 停止生成按钮 + 路由解释 + 纠正提示
- ✅ 首次引导隐私声明 + 动态 placeholder + 能力发现
- ✅ 功能菜单入口（⋯ 下拉 6 个功能）
- ✅ 消息复制按钮
- ✅ Agent 彩色色带（蓝/金/紫/绿/灰）
- ✅ 质量审查用户友好文案（✅ 可靠 / ⚠️ 仅供参考 / 🚫 风险高）
- ✅ 会话自动命名（第一条消息前 15 字）
- ✅ 会话列表时间分组（今天/最近7天/更早）
- ✅ 删除会话 Undo Toast（5 秒内可撤销）
- ✅ 骨架屏加载（切换会话时）
- ✅ 思考状态进度提示（正在分析… → 连接专家中…）
- ✅ 欢迎消息隐私提示（🔒 对话仅存储在本地）
