```

│  ├─ EmbeddingLoopDetector (循环检测，相似度0.88)                │
│  ├─ ToolResultClassifier (结果分级: TIMEOUT/EMPTY/GARBAGE)      │
│  └─ TokenBudgetManager (预算分级: Normal/Compact/Compress)      │
│                                                                 │
│  Layer 4: 质量审查                                              │
│  ├─ QualityGuardAgent (REVIEW/RED_TEAM)                         │
│  ├─ QualityModeResolver (意图+LLM风险分类)                      │

│                                                                 │
│  Layer 5: 审计追踪                                              │
│  ├─ EventBusAdapter (异步事件发布)                              │
```
