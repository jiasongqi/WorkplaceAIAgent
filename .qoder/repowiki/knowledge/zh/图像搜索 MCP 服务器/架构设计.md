- 采用 Spring Boot 3.4 与 Spring AI MCP Server Starter 构建，遵循标准 Spring 应用结构。
- 核心逻辑位于 `ImageSearchTool`，通过 `@Tool` 注解暴露为 MCP 工具，由 `YuImageSearchMcpServerApplication` 中的 `MethodToolCallbackProvider` Bean 注册。
- 支持 SSE 和 STDIO 两种传输协议，通过 `application-sse.yml` 和 `application-stdio.yml` 进行配置切换，默认激活 SSE 模式。
- 依赖 Hutool 处理 HTTP 请求与 JSON 解析，直接调用 Pexels API 获取图像数据。
