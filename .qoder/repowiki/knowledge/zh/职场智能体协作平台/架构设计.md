- **多模块协同**：后端 (`backend`) 作为核心编排器，通过 HTTP/SSE 向前端 (`frontend`) 提供流式交互，并通过 MCP 客户端协议调用外部工具服务器 (`image_search_mcp`)。
- **统一技术底座**：所有 Java 模块均基于 Spring Boot 3.4+ 与 Spring AI 1.0 构建，共享 `spring-ai-bom` 依赖管理，确保了模型接口与向量存储（PGVector）的一致性。
- **标准化通信契约**：后端定义了统一的 `AgentOutput` 与 `ExecutionResult` 模型，前端通过 Axios 封装统一 API 层，MCP 服务器则遵循标准 WebMvc 暴露工具能力，实现了跨模块的松耦合集成。
