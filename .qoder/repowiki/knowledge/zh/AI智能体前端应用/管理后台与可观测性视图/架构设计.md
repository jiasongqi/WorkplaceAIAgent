- 采用 Vue 3 Composition API (`<script setup>`) 构建独立的管理与观测视图，包括 `AdminDashboard`（入口导航）、`UsageDashboard`（用量统计）、`CompareView`（Agent 对比）和 `TraceDetail`（轨迹详情）。
- 通过 `../api` 模块封装后端交互，统一处理 JWT 认证拦截与 SSE 流式通信（如 `getUsageStats`, `getTrace`, `chatWithOrchestrator`）。
- `TraceTimelineView` 作为通用展示组件，被 `TraceDetail` 等视图复用，实现执行步骤的可视化渲染与状态同步。
- 视图间通过 `vue-router` 进行导航，数据加载逻辑集中在各视图的 `onMounted` 钩子中，部分场景（如 Trace 运行中）采用轮询机制更新状态。
