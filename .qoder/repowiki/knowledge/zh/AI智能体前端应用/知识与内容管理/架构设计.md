- 采用 Vue 3 Composition API (`<script setup>`) 构建单文件组件 (SFC)，包含 `KnowledgeBase.vue`（知识库）、`ArtifactAdmin.vue`（交付物管理）和 `Favorites.vue`（收藏）。
- 通过 `../api` 模块封装的 Axios 实例与后端交互，利用请求拦截器自动注入 JWT Token，并在 `ArtifactAdmin` 中实现管理员特权登录逻辑。
- 界面遵循统一的 Header-Content 布局，使用 CSS Variables (`--glass-bg`, `--surface`) 维持视觉一致性，并通过 `vue-router` 实现页面导航。
