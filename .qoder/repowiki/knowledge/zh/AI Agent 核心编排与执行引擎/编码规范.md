- 所有 Agent 类均继承自 BaseAgent，通过重写 step() 方法实现具体的单步执行逻辑，并由基类统一管理 IDLE/RUNNING/FINISHED 状态流转。
- 流式接口统一使用 SseEmitter 或 Flux<String> 作为返回类型，并在异步线程中执行耗时操作，通过 emitter.send() 实时推送 token 级响应。
- 敏感配置（如 API Key、JWT Secret）严禁硬编码，必须通过 ${ENV_VAR:default} 格式从环境变量注入，并在 application.yml 中提供占位符。
- 跨模块依赖通过构造函数注入或 @Resource 注解实现，核心业务逻辑（如 OrchestratorAgent）采用手动 new 实例或工厂模式以支持请求级隔离。
